# -Prudentia-Credit-Risk-Regulatory-Reporting-Platform-for-a-Bank
–	Authored the Business Requirements Document (BRD), Functional Specification (FSD) and as-is/to-be process flows for a bank credit-risk and regulatory reporting platform
–	Managed a backlog of 30+ user stories with acceptance criteria as epics and features in Azure DevOps, delivered across 3 Agile sprints
–	Built a PostgreSQL data warehouse (star schema) and SQL rules to classify credit risk, flag non-performing loans and calculate loan-loss provisions from the loan book
–	Added an ESG climate overlay on loan exposure for regulatory reporting, and designed Power BI dashboards for credit-risk trends, overdue loans and provision coverage
–	Coordinated system integration testing (SIT) and user acceptance testing (UAT), logged defects, obtained business sign-offs, and prepared release notes and go-live validation
–	Tech Stack: SQL, PostgreSQL, Power BI, Azure DevOps, Python
